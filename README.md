

# Welcome to Starflight Supernova

a simple to learn and use JavaScript based game engine with so many features such as...

-   premade player, ground, and physics systems
-   an easy to use code editor inside the editor
-   a basic UI system with buttons and text
-   programable objects so you can make custom assets
-   easy to use level system
- quick to learn editor
